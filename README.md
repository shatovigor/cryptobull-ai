# 🤖 CryptoBullAI

Крипто-торговый бот для Bybit с несколькими стратегиями, бэктестом и модульным GUI.

## ✨ Возможности

### Торговые стратегии
- **📊 Уровни + паттерны (classic_levels)** — поиск горизонтальных уровней + сигналы по пинбару и bounce
- **📈 TrendRider (trendrider)** — трендовая стратегия на EMA/RSI/ADX с MTF-фильтром
- **🧠 Адаптивная ML (adaptive_ml)** — онлайн-обучаемая модель на 15 фичах (требует 50+ сделок)

### Управление рисками
- Адаптивный стоп/тейк по ATR
- Адаптивный размер позиции по волатильности
- Trailing stop (адаптивный по ATR)
- Дневной стоп по P&L
- Cooldown между сделками
- Автоисключение убыточных монет

### Автоподбор монет
- **Под депозит** — пересчёт списка монет под free balance
- **По рынку** — сканер Bybit по ATR, объёму, цене
- **CoinManager** — исключает монеты с плохой статистикой

### Бэктест
- **Одиночный прогон** — одна стратегия, один период
- **A/B функции** — сравнение MTF / Trailing / Adaptive / Pyramid / Hedge
- **A/B параметров входа** — сравнение MIN_TOUCHES, NEAR_LEVEL, CLUSTER
- Учёт комиссий, слиппеджа, funding
- Без look-ahead bias

### GUI
- Модульный PyQt6-интерфейс
- Тёмная тема, единый стиль
- Автосинхронизация с биржей в фоновом потоке
- Live-графики цены и equity
- Календарь P&L и тепловая карта монет
